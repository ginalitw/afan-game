# 阿飯餵飯糰・棚田 Phaser 3 試作（獨立測試頁，不影響根目錄第五版）

- 阿飯所有影格、飯糰道具：用 rembg（isnet-general-use）從原始影片影格重新去背，填補內部空洞（飯糰白飯保持不透明），邊緣 1px 去白邊。
- 背景 mid/near：洋紅色底以實際底色（約 255,78,254）反混色去背，避免粉紅邊。
- 路徑：沿原圖上畫的路描點（tools/path.json），樣條平滑；兩條岔路走進田裡深處，阿飯大小隨深度變化。
- 遮擋：橋的前欄杆、五個立牌從原圖切出，依「底線 y」與阿飯腳的 y 排序。
- 操作：桌機 ← → ↑ ↓、空白鍵餵；手機按住畫面往手指方向走、點立牌。
- `?debug` 顯示路徑，`?season=winter` 指定季節。
