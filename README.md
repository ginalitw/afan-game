# 阿飯餵飯糰 第四版原型

手繪橫向捲動散步地圖：阿飯沿著彎曲小路上下坡走，三段關卡（入村，棚田，遠山），霧會隨探索散開，抵達作品立牌玩 10 秒接稻穗小遊戲。

* `scroll/far.webp`，`mid.webp`，`near.webp`：由 s1／s2／s3 去背處理的三層視差圖
* `scroll/afan/`：阿飯走路與動作圖（背影，不露臉）
* 路徑座標寫在 `app.js` 的 `PATH_PTS`（原圖 4128x1024 座標）
* localStorage `afanV4Records` 只存 `{id,date,size,type}`
* 第三版保留在 `v3/`（僅本機）

## 第四版之一：互動小物

* `items/`：稻草人，麻雀，柿子枝，稻架，紅蜻蜓，貓咪，炊煙（由 Gemini 洋紅底圖切格去背，WebP）
* 稻穗叢沿用 `sprites/rice.png` 三根疊成一叢，亮點用程式畫
* 每樣小物每天第一次點擊送一顆小飯糰，存在 localStorage `afanV41PropBonus`，只存 `{p,d,n}`，和作品紀錄分開，不影響柵欄
* 支援減少動態設定

## 第四版之二：每段一個關主

* 接稻穗小遊戲只在每段離柵欄最近的立牌出現，當作關主：入村 02，棚田 04，遠山 05
* 難度（`app.js` 的 `HARD`）：入村每 380 毫秒落一個，速度 140 到 220，葉子 25%；棚田每 320 毫秒，速度 190 到 290，葉子 40%；遠山同棚田，再加每 1.4 秒一隻麻雀橫飛，會叼走經過的稻穗，碰到阿飯偷走兩束
* 其他立牌抵達就有幾秒鐘的輕互動，可跳過，依序輪流：翻翻立牌，幫稻草人戴斗笠，找找麻雀，敲敲木樁（相鄰不重複）；目前 01 翻翻立牌，03 戴斗笠
* 輕互動直接給的飯糰記成 small／normal，和小遊戲按跳過一樣，中大飯糰與黃金飯糰留給關主
* `items/scarecrow_nohat.webp`，`straw_hat.webp` 由稻草人第一格裁切
* 重新開始會一起清掉小物的小飯糰
