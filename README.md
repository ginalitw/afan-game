# 阿飯餵飯糰 第五版

手繪橫向捲動散步地圖，六段章節首尾相連：棚田，廢校與山村，清津峽，信濃川・河岸段丘，苗場，松之山。阿飯一路走下去，霧與柵欄按章節開放。

* `v5/<季節>/`：每段的中景（`<章節>_mid.webp`），遠景，近景，四季各一套（春夏秋冬），預設跟著現在的真實季節，可在上方切換，只載入目前章節附近
* 路徑與立牌座標寫在 `app.js` 的 `CHAPTERS`（百分比），`oy` 是整段上下位移，讓接縫處路面對齊
* `v5/afan/`：阿飯（不露臉）走路向右，走路向左（不鏡像），吊橋蹲下，拿飯糰動畫
* `v5/items/`：各章節道具（洋紅底去背，WebP）
* 立牌只放木牌與作品編號，不畫作品
* 每段一個關主大互動：棚田接稻穗，廢校敲校鐘叫出動物，清津峽過搖晃吊橋（點一下停住），信濃川釣魚三回，苗場坐纜車點星星，松之山滾雪球堆雪人（雪人不畫臉）
* 其他立牌是幾秒鐘的輕互動，給小飯糰
* 世界小物每天各點一次送小飯糰
* localStorage `afanV5Records` 存 `{v:5,records,bonus,season}`，不動舊的 `afanV4Records`，`afanV41PropBonus`；重新開始只清第五版資料
